# TFG - Análisis espectral y filtrado digital de señales ECG

Este repositorio contiene el notebook desarrollado para el Trabajo de Fin de Grado sobre análisis espectral y filtrado digital aplicado a señales ECG sintéticas.

## Contenido

- Generación de señales ECG sintéticas mediante el modelo de McSharry
- Análisis espectral mediante técnicas de Fourier
- Aplicación de filtros digitales
- Comparación entre distintos filtros
- Evaluación morfológica de señales filtradas

## Archivo principal

- `analisis_filtrado_ecg_sintetico.ipynb`: notebook principal con los experimentos y análisis realizados
